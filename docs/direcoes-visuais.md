# Direções visuais da Lira de Bolso

Três identidades foram desenhadas em 11/11/2026 e comparadas lado a lado na página de modelos (canvas "Lira de Bolso — direções visuais", no Claude). A **2 · Cerâmica de figuras negras** foi escolhida e aplicada na versão 0.4. As outras duas ficam guardadas aqui para uso futuro, por exemplo como temas alternativos.

## 1 · Mármore e Egeu

Clara e serena, da mesma família visual do Corredor Invertido.

| Papel | Cor |
| --- | --- |
| Fundo | `#eff0eb` (mármore) |
| Superfícies | `#fafaf6`, bordas `#d6dad2` |
| Texto | `#1e2a31`, secundário `#5b6a70` |
| Destaque | `#2f6c8c` (azul do Egeu) |
| Cordas | `#a8823a` (bronze); travessa `#b08a43` |
| Corda tocada / gravar | `#c4553f` (terracota) |

Fontes: Marcellus (títulos), Inter (texto). Cordas numa moldura com travessa de bronze e caixa de som em mármore.

## 2 · Cerâmica de figuras negras (em uso)

Inspirada nos vasos gregos: terracota, formas pretas, faixa de grega, a lira como silhueta de vaso.

| Papel | Cor |
| --- | --- |
| Fundo | `#d06c42` (terracota; o modelo usava `#c8643b`, clareado para o texto preto passar de 4,5:1) |
| Formas, texto, botões | `#1b1512` (preto) |
| Sobre o preto | `#f1dfbd` (creme): travessa, aba escolhida, texto dos botões |
| Cordas | `#e08a55`; corda tocada ou acesa `#f6efe0` |
| Nomes das notas | `#cdb894` |
| Trilhos e linhas discretas | `#a9502b` |

Fontes: Cinzel (títulos, letras de inscrição), Inter (texto). Abas em pílula preta, botões e chips com contorno preto (preenchidos quando escolhidos), faixa de grega sob o título.

## 3 · Noite no templo

Escura de propósito, com cordas douradas que brilham; combina com o modo relaxar.

| Papel | Cor |
| --- | --- |
| Fundo | `#121829` (azul-noite) |
| Superfícies | `#1a2238`, bordas `#2a3452` |
| Texto | `#ece6d6`, títulos `#f3e6c4`, secundário `#9aa3b8` |
| Cordas e travessas | `#d9b26a` (ouro); corda tocada `#ffe7ad` com brilho |
| Aba escolhida | `#d9b26a` com texto `#121829` |
| Chip escolhido, progresso | `#8fb4d8` (luar) |
| Gravar | `#e07a63` |

Fontes: Cormorant Garamond (títulos), Inter (texto). Uma lua em traço no canto do título.

Ideia guardada: usar a 1 como tema claro e a 3 como tema escuro, seguindo o aparelho.
